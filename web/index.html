Validador universal

¿Cómo funciona?

Los dígitos de control se calculan con reglas matemáticas. Ayudan a detectar errores al escribir un código, pero no demuestran que un documento, libro, cuenta o tarjeta exista.

  • DNI/NIE: el resto de dividir el número entre 23 selecciona una letra de control.
  • ISBN-10: suma ponderada módulo 11; el control puede ser X.
  • ISBN-13 y EAN-13: suma ponderada con pesos 1 y 3; se completa hasta un múltiplo de 10.
  • IBAN español: se reordenan los caracteres y se comprueba que el resto módulo 97 sea 1.
  • Tarjeta (Luhn): se duplican dígitos alternos desde la derecha y la suma debe ser múltiplo de 10.

En cada validación se muestran los pasos y el resultado concreto del cálculo.

Modo experimento: ¿qué errores detecta?

La aplicación genera códigos sintéticos con un control correcto, altera un dígito o intercambia dos dígitos contiguos y vuelve a validarlos. No se usan ni se envían datos personales.

El porcentaje es la proporción de errores introducidos que el algoritmo detectó en estas pruebas; depende de los errores simulados y no representa todos los casos posibles.
